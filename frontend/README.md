# 一行

同じニュースを1行として扱い、各新聞社の報道・要約・社説を並べて読むための閲覧アプリです。

## 見方

- **1行 = 同じ出来事の同じ版**。朝日・読売・毎日などが別記事でも、同一の初報／同一の続報なら1行に束ねます。
- **v1 は初報**。続報は **v2 以降として別行** に出し、版のチップから行き来できます。
- **重要** と **新着** は別タブです。**すべて** で全行を時系列に見られます。

初版は紙面の読み方を確かめるためのサンプル稿です。通信社APIやクローラはまだ繋いでいません。

```bash
npm install
npm run dev
```
